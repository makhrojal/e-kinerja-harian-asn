# Kontribusi

Gunakan fixture sintetis. Pertahankan skema inti sepuluh kolom dan izin web app pribadi. Perubahan auth, migrasi, upload, ekspor, atau akses publik memerlukan uji konflik/retry dan review privasi.

Sebelum mengirim perubahan, jalankan `npm test` dan jelaskan perilaku sebelum/sesudah, bukti verifikasi, serta gate cloud yang belum diuji.
