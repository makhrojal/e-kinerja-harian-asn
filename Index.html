Bagi Template Bersih ke Rekan ASN

Master ini hanya spreadsheet kosong tanpa catatan pribadi. Agar menjadi aplikasi, penerima juga harus memasang kode rilis di Apps Script dan membuat deployment miliknya sendiri.

1
Buat Salinan Master Spreadsheet:

Buka tautan master template berikut dan klik tombol Buat salinan (Make a copy).

2
Pasang kode aplikasi:

Pada salinan baru, buka Extensions → Apps Script, lalu pasang source dari paket rilis resmi E-Kinerja. Salinan Sheet saja belum memiliki menu atau aplikasi. Paket rilis publik belum tersedia; jangan kirim tautan ini sebagai aplikasi siap pakai.

3
Siapkan dan deploy milik penerima:

Jalankan E-Kinerja ASN → Siapkan salinan ini, setujui izin Google, lalu Deploy → New deployment → Web app dengan akses pribadi. Gunakan URL /exec deployment penerima, bukan URL aplikasi pembuat template.

Izinkan akses Google Drive

Aplikasi memerlukan izin untuk membuat master template bersih serta menyimpan laporan WFH sebagai Google Docs dan PDF di Drive Anda.

Jika Anda memilih Bagi Template Bersih: aplikasi membuat spreadsheet kosong terpisah, tanpa kegiatan atau profil Anda, lalu membagikannya sebagai Siapa saja yang memiliki link — Pelihat. File laporan WFH tetap privat.

Google akan menampilkan layar persetujuan untuk project Apps Script milik Anda. Setelah selesai, kembali ke tab ini dan periksa izin.
